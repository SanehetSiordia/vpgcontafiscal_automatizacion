# proyecto, no supuestas:

#   * psycopg[c]==3.2.3 NO compila con el gcc 15 de Alpine 3.22 (numutils.c
#     declara UINT64CONST(10000000000000000000) y gcc 15 lo rechaza por
#     desbordamiento). 3.2.13 si compila.

# en el runtime solo para eso seria peor. La variante C enlaza libpq de forma
# normal y el runtime solo necesita el paquete `libpq`.
